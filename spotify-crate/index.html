One-time setup

Crate talks to Spotify directly from this browser tab. There is no server and nothing is uploaded anywhere — your playlists are cached in this browser only. To let it in, Spotify needs you to register a (free) app and paste its ID here.

  1. Open the Spotify developer dashboard and click Create app. Any name will do.
  2. Set the Redirect URI to exactly this, and click Add:
  3. Under Which API/SDKs are you planning to use? tick Web API, then save.
  4. Open the app's Settings, copy the Client ID, and paste it here:

Search syntax

  • artist: album: track:
  • playlist: the month's name
  • year:1998
  • year:1990-1999
  • "exact phrase"
  • artist:"two words"

Terms combine with AND.

Which playlists make up your crate?

Tick the monthly playlists you want to search. Everything else on your account is ignored. You can change this at any time.
